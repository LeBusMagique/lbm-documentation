# lebusmagique-symfony-wordpress

## Role du projet

Première génération technique du Bus Magique combinant Symfony et WordPress.
Le dépôt représente l’historique de l’ancien socle site/backend.

## Statut

- **Etat** : A archiver
- **Stack** : Symfony, WordPress, PHP
- **Successeur principal** : `lebusmagique-api` pour la partie backend moderne

## Valeur patrimoniale

- Historique des premiers flux de production.
- Ressource utile pour récupérer des contenus, migrations ou règles métier oubliées.

## Risques / dette identifiés

- Process de déploiement legacy (scripts manuels, FTP/SSH).
- Architecture monolithique difficile à maintenir.
- Confusion potentielle avec le socle actif si non archivé.

## Plan recommandé

- Auditer les dépendances actives éventuelles vers ce dépôt.
- Migrer les éléments utiles restants vers les repos cibles.
- Archiver officiellement le projet une fois les dépendances supprimées.
