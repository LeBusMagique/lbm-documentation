# newsletters

## Role du projet

Dépôt des templates et assets de newsletters LeBusMagique.
Il sert à produire les campagnes mail à partir de structures HTML/MJML.

## Statut

- **Etat** : Faible activité
- **Stack** : HTML, MJML, assets graphiques
- **Usage** : ponctuel selon les campagnes éditoriales

## Contenu principal

- Templates de newsletter (`LBM_00/*.mjml`, `LBM_00/*.html`).
- Ressources visuelles (logos, réseaux sociaux, images de sections).

## Risques / dette identifiés

- Absence de README opératoire.
- Process de génération/envoi non documenté dans le repo.

## Actions recommandées

- Ajouter un workflow clair : éditer, compiler, valider, diffuser.
- Documenter les prérequis MJML et les conventions de nommage.
- Définir un système de version des campagnes.
